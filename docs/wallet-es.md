# Wallet Paybrok

Paybrok esta disenado alrededor de autocustodia. El usuario controla sus credenciales de wallet, y Paybrok no guarda la seed phrase del usuario en servidores de Paybrok.

## Wallet Mobile

En mobile, Paybrok permite:

- Crear wallet.
- Restaurar wallet.
- Enviar activos.
- Recibir activos.
- Escanear QR.
- Ver balances.
- Ver movimientos.
- Usar links y QR de pago Paybrok.

## Wallet Web

En web, Paybrok soporta:

- Wallet web Paybrok con boveda local cifrada.
- Contrasena local para desbloquear acciones sensibles.
- Recuperacion con palabras si el almacenamiento local se pierde.
- Freighter como opcion avanzada de firma externa.

## Recuperacion

El usuario debe guardar sus palabras de recuperacion.

Paybrok nunca pedira palabras de recuperacion por:

- Telegram.
- Email.
- Soporte.
- Telefono.
- Redes sociales.
- Mensajes de proveedores.

Si el usuario pierde el dispositivo o almacenamiento del navegador y no tiene sus palabras, Paybrok no puede recuperar la wallet.

## Activos

La disponibilidad de activos puede variar por plataforma y configuracion. Paybrok se enfoca en activos sobre Stellar como:

- USDC.
- EURC.
- XLM.
- BROK donde este habilitado.
