# Public Roadmap

This roadmap is public and high-level. It does not expose internal architecture, secrets, code, or private implementation details.

## Current Focus

- Improve wallet onboarding.
- Improve web wallet reliability.
- Improve notifications.
- Expand local QR payment handling.
- Improve protected service payments.
- Improve P2P and remittance flows.
- Improve provider experience.
- Improve public documentation.
- Continue security and compliance hardening.

## Near-Term Goals

- Public product documentation.
- Clear user education around recovery words and escrow.
- Better provider onboarding.
- Better service contract language.
- More consistent QR local payment flows.
- More visible dispute guidance.

## Long-Term Direction

- More countries and payment methods.
- More reliable provider liquidity.
- More transparent escrow flows.
- Better public trust materials.
- More partner and merchant documentation.
