# Retiro de efectivo

1. Abre Retiro y solicita un retiro.
2. Escanea el QR o pega la wallet aprobada del Punto.
3. Selecciona activo y monto y revisa tasa, efectivo neto, comision y vencimiento.
4. Envia la solicitud. Todavia no se retienen fondos.
5. El Punto acepta y el usuario firma Proteger fondos.
6. El Punto entrega efectivo unicamente con estado Protegido.
7. El usuario cuenta el total y confirma la recepcion.
8. El Punto firma Cobrar.

Si vence despues de proteger sin completarse, la wallet creadora usa Recuperar
fondos y espera la confirmacion de Stellar. Retiro es efectivo; para una
transferencia bancaria al beneficiario se usa Remesas cuando exista un Punto
compatible.
