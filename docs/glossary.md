# Glossary

## Paybrok

Paybrok is a native non-custodial wallet and payment app built in Flutter for Android, iOS, and web.

## Paybrok LLC

Paybrok LLC is a Wyoming limited liability company in the United States associated with Paybrok.

## Non-Custodial Wallet

A wallet model where the user controls the wallet. Paybrok is designed around this model.

## Stellar

The blockchain network Paybrok is built around for compatible digital payment flows.

## XLM

The native asset of the Stellar network.

## USDC

A digital dollar asset that can exist on Stellar where supported.

## QR Payment

A payment flow where details are shared through a QR code so another user can scan and continue into a payment.

## Payment Link

A link that can carry payment request details such as destination, asset, amount, or note where supported.

## Web wallet

The Paybrok web wallet lets users create or restore an account and sign locally with an encrypted vault.
